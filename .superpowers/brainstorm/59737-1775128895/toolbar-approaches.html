Text Optimize Toolbar — Approach Comparison

Two approaches for the fixed toolbar + review flow. Consider citation safety and UX.

A

Inline Preview Panel (Recommended)

Optimize buttons live in the existing toolbar row. When AI returns the result, a preview panel slides in between the toolbar and textarea, showing the optimized text with an Accept/Discard button pair. The textarea is dimmed but visible beneath.

Pros

  • User sees the result in context before applying
  • Clear accept/discard affordance
  • Citation markers visible in preview
  • Simple to build — no diff library needed

Cons

  • Can't see original and new side-by-side
  • Preview panel takes vertical space
B

Side-by-Side Diff Panel

Same toolbar buttons, but when AI returns, the textarea splits into two columns: original (left) vs optimized (right). User reviews both and clicks Accept or Discard. Citations are highlighted in both panels.

Pros

  • Direct visual comparison — easy to spot changes
  • User can verify citations preserved at a glance
  • Professional diff experience

Cons

  • More complex to build (split layout, scroll sync)
  • Horizontal space may be tight
  • Overkill for small text selections
